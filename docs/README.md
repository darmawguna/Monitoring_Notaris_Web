Sistem manajemen kantor notaris digital untuk Kantor Notaris Komang Hendy Prabawa.

## Daftar Dokumen

| No | Dokumen | Deskripsi |

| 1 | [Ringkasan Fitur](./fitur-lengkap.md) | Daftar semua fitur yang sudah selesai |

## Tech Stack

- **Backend:** Laravel 12, PHP 8.2
- **Admin Panel:** Filament 3.3
- **Document Generation:** PhpWord (template .docx)
- **Database:** MySQL / SQLite
- **Deployment:** Docker (Laravel Sail), GitHub Actions CI/CD
